# Kae Mods: продуктовый разбор раздела Minecraft

Анализ по коду, без изменений кода. UI в приложении при подготовке не запускался: выводы про состояния экранов и доступность нужно подтвердить на живом интерфейсе.

## 1. Обзор

**Что это.** Kae Mods: менеджер модов на Tauri 2 (Rust + React). Основной продукт для Deadlock, Minecraft добавлен вторым разделом. Каркас общий: каталог, сборки, библиотека, диагностика.

**Minecraft** (`src-tauri/src/minecraft/*`, `src/features/minecraft/*`):

- версии игры, загрузчики Fabric, Quilt, Forge, NeoForge;
- автоскачивание Java;
- запуск, консоль и логи;
- каталог Modrinth и CurseForge;
- импорт `.mrpack` и своего `.kaepack`, шеринг;
- обновление отдельных модов с Modrinth.

**Для кого.** Игроки, которые ставят моды без возни: оффлайн и пиратские клиенты, небольшие сборки, обмен с друзьями.

**Ключевые сценарии**

| Сценарий | Как сейчас |
|---|---|
| Онбординг | Отсутствует. В `welcome/` и `home/` Minecraft не упомянут, пользователь попадает на пустой список |
| Создание сборки | Окно: имя, версия, загрузчик (`Create` в `Instances.tsx`) |
| Установка сборки | Каталог Modrinth или CurseForge, импорт файла, установка с зависимостями |
| Запуск | «Играть», подготовка и Java, затем консоль и логи |
| Обновление | Только отдельные файлы Modrinth. Обновления самого модпака нет |
| Авторизация | Только оффлайн-ник, вход через Microsoft «скоро» |

## 2. Функционал

Impact и Effort: S малый, M средний, L большой.

| # | Проблема → решение → эффект | Impact | Effort | Приоритет |
|---|---|---|---|---|
| F1 | **Пустой старт.** Новый пользователь видит пустой список и сам выбирает версию и загрузчик. Решение: первый запуск с ником и кнопкой «Создать готовую сборку» (последний релиз + Fabric), позже варианты «Выживание», «Оптимизация». Эффект: время до первой игры падает с минут до пары кликов. | Высокий | S | **P0** |
| F2 | **Ошибки сырыми строками.** `explain()` в `Minecraft.tsx` знает 5 кодов, остальное попадает в баннер как есть (`http 403`, `could not start Java`). Падение игры не детектируется: `is_running` в `launch.rs` только проверяет процесс. Решение: коды выхода и `crash-reports/` превращать в плашку «Игра упала: нехватка памяти / старая Java / мод X» с кнопкой «Открыть лог». Эффект: меньше обращений «не запускается». | Высокий | M | **P0** |
| F3 | **Баг времени игры.** `play_secs` добавляется только в `mc_running`, который опрашивает открытая страница раз в 3 с. Закрыли лаунчер во время игры, открыли через день: засчитаются сутки. Решение: считать по факту завершения процесса (фоновый поток или метка выхода). Эффект: корректная статистика и presence. | Средний | S | **P0** |
| F4 | **Только оффлайн-аккаунт.** Серверы с online-mode недоступны. Решение: вход Microsoft через device code. Нужен одобренный Mojang Client ID, это внешняя зависимость. Эффект: доступ к серверам, лицензионный сегмент. | Высокий | L | P1 |
| F5 | **Ключ CurseForge.** Нужно получить и вставить свой API-ключ, поиск при этом отвечает 403 непоследовательно. Решение: по умолчанию Modrinth, CurseForge прятать за «Подключить» либо вшить ключ или прокси. Эффект: нет тупика с красным баннером. | Средний | S–M | P1 |
| F6 | **Жизненный цикл сборки.** Нет «Клонировать», «Починить профиль», обновления установленного модпака, резервной копии миров. Решение: клон (копия папки), «Починить» (повторный `install_version` с проверкой sha1), «Обновить модпак» (сравнить версию проекта), бэкап `saves/` перед обновлением. Эффект: пользователь не боится трогать сборку. | Высокий | M | P1 |
| F7 | **Обновления модов с ограничениями.** Проверка хэширует все файлы при каждом открытии страницы (`check` в `Detail`), моды CurseForge не покрыты. Решение: кеш хэшей по mtime и размеру, проверка раз в N часов, пометка «источник неизвестен». Эффект: быстрее страница, честнее статус. | Средний | S | P2 |
| F8 | **Установки живут в баннере.** Один глобальный `mc-progress` без очереди и отмены, хотя в Deadlock есть страница Downloads. Решение: показывать установки Minecraft в ней: очередь, отмена, повтор. Эффект: единая модель загрузок. | Средний | M | P1 |
| F9 | **Память вслепую.** По умолчанию 4096 МБ, ползунок до 32768 без учёта ОЗУ. Решение: читать объём ОЗУ, предупреждать о выходе за 70–75% и подбирать рекомендуемое по числу модов. Эффект: меньше лагов и вылетов. | Средний | S | P1 |
| F10 | **Discord presence без игры.** Статус зависит от страницы лаунчера (`presence.ts`), хотя параметр `timer` уже есть. Решение: при запуске писать «Играет в <сборка>» с таймером. Эффект: бесплатная соцпрорекламка. | Низкий | S | P2 |
| F11 | **Шеринг только файлом.** В Deadlock уже есть коды профилей (`profiles.rs`, `CODE_PREFIX`). Решение: те же короткие коды для `.kaepack`, импорт перетаскиванием файла. Эффект: сборкой можно поделиться одной строкой в чате. | Средний | M | P2 |
| F12 | **Глобальное под шестерёнкой «Сборок».** Аккаунт, хранилище и ключ лежат там, хотя они общие. Решение: вынести в общие «Настройки» и в онбординг. Эффект: меньше путаницы. | Низкий | S | P2 |

## 3. Дизайн и UX

| # | Проблема → решение → эффект | Impact | Effort | Приоритет |
|---|---|---|---|---|
| D1 | **Каталог без контекста.** Установка идёт в «выбранную» сборку (`selected`), заданную маленьким селектом. После установки результат виден только в баннере. Решение: закреплённая плашка «Ставим в: X», кнопка «Открыть сборку» в баннере успеха. Эффект: меньше установок не туда. | Высокий | S | **P0** |
| D2 | **Нет сортировки и категорий каталога.** `SearchReq` умеет только запрос, тип, версию и загрузчик. Решение: сортировка (популярные, новые, обновлённые), категории Modrinth, совместимость с версией сборки на карточке. Эффект: быстрее находится нужный мод. | Высокий | M | P1 |
| D3 | **Библиотека не масштабируется.** Плитки без поиска, сортировки, групп и компактного вида. Решение: поиск, сортировка по последнему запуску, закрепление, вид «список». Эффект: удобство при 10+ сборках. | Средний | S–M | P1 |
| D4 | **Тяжёлые картинки.** Обложки (`mc_covers`) и скриншоты передаются как data-URI: весь файл в base64 через IPC. Решение: `asset://`-протокол или миниатюры на стороне Rust. Эффект: плавная вкладка «Скриншоты». | Средний | M | P1 |
| D5 | **Системные диалоги.** `window.confirm` для удалений (2 места) выбивается из стиля. Решение: свой диалог с названием и последствием. Эффект: единый вид и безопасность. | Низкий | S | P2 |
| D6 | **Доступность модалок и меню.** В `Modal` есть Esc, но нет фокус-ловушки и возврата фокуса. У кнопки закрытия `aria-label="close"` не локализован. Меню ⋮ без навигации стрелками и Esc, консоль не `aria-live`. Решение: фокус-ловушка, локализация, клавиатура в меню. Эффект: работа с клавиатуры и скринридера. | Средний | S | P1 |
| D7 | **Состояния экранов.** Пустые состояния есть, но «ошибка каталога», «офлайн», «нет Java» показываются текстовым баннером. Решение: единые состояния (скелетон, ошибка с «Повторить», офлайн из кеша). Эффект: меньше ощущения «зависло». | Средний | M | P1 |
| D8 | **Однотипные обложки.** Градиент и буква одинаковы у многих сборок. Решение: иконка загрузчика на плитке, для импортов брать иконку проекта (Modrinth `icon_url`). Эффект: узнаваемость. | Низкий | S | P2 |
| D9 | **Список версий загрузчика без пометок.** Решение: «рекомендуемая» и «последняя», предупреждение о смене версии у сборки с модами. Эффект: меньше случайных поломок. | Средний | S | P1 |

## 4. Топ-5 с максимальным эффектом

1. **F1 + D1: онбординг и «Создать готовую сборку».** Закрывает самый крутой провал воронки при малой стоимости.
2. **F2: понятные ошибки и детект падения игры.** Главная боль любого лаунчера, снижает нагрузку на поддержку.
3. **F3 + F10: честное время игры и presence «Играет в …».** Малый объём, исправляет реальный баг в `mc_running`.
4. **F6 + D3: клон, «починить профиль», обновление модпака и удобная библиотека.** Превращает набор сборок в управляемую библиотеку.
5. **F4: вход через Microsoft.** Крупная работа с внешним допуском Mojang, но единственное, что открывает онлайн-серверы. Параллельно F5 (CurseForge без ключа), чтобы не упираться в 403.

Самые дешёвые для старта: F3 и D1.
